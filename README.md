# Spot the Difference Symbol Grid Puzzle

A procedurally generated puzzle game that presents two side-by-side grids of symbols and challenges you to find and click all the cells that differ between them, with a live timer, hint mode, and three difficulty levels.

## Features

- Three difficulty levels: Easy (4×4 grid, 3 differences), Medium (6×6, 5 differences), Hard (8×8, 8 differences)
- Procedurally generated grids — every game is unique
- Click cells in Grid B to mark differences; correct finds are highlighted in green
- Timer counts up from zero for each round
- Hint button briefly highlights a random unfound difference cell
- Found counter tracks progress in real time
- Win detection with congratulation message and timer stop
- "Not a difference" feedback for incorrect clicks without penalty
- Accessible grid cells with ARIA roles and labels
- New game button and difficulty selector for instant replay
